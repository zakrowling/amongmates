# Assets

Among Mates draws everything itself (the ship, crewmates, bodies, ghosts and task mini-games are drawn on canvases) and synthesizes its sound effects with Web Audio. The background music is an mp3.

| Path | Used for |
|------|----------|
| `sounds/mrwashingt0n-deep-work.mp3` | Background music during each round (quiet, crossfaded loop) |
| `image/amongmates-logo.png` | Lobby title logo (a text title shows if it is missing) |

The UI font is [Just Another Hand](https://fonts.google.com/specimen/Just+Another+Hand), loaded from Google Fonts.
